# ondo

[English](README.md) · 한국어

맥북 뚜껑을 닫아도 잠들지 않게 하는 메뉴바 앱입니다. 깨어 있는 동안 CPU·배터리 온도와 전원을 지켜보다가, 과열되거나 충전기가 빠지면 스스로 깨어있기를 풀고 맥을 재웁니다. Amphetamine·KeepingYouAwake와 다른 점은 이 과열 보호입니다.

토리랩스(Tory Labs)의 무료 오픈소스 앱이며, MIT 라이선스로 공개합니다. 소개 페이지: https://torylabs.dev/ko/ondo

- Apple Silicon Mac, macOS 13 이상 (Intel Mac은 빌드는 되지만 실기기에서 확인하지 않았습니다)

## 설치

**Homebrew**

```sh
brew install --cask su-record/tap/ondo
```

앱과 함께 터미널 명령 `ondo`도 설치됩니다.

**DMG**: [GitHub 릴리스](https://github.com/su-record/ondo/releases)에서 받아 ondo를 응용 프로그램 폴더로 옮깁니다. 앱은 Apple 공증을 받았습니다.

### 처음 실행

1. ondo를 열면 메뉴바에 덮인 노트북과 온도계 아이콘이 생깁니다.
2. 처음 「닫아도 깨어있기」를 켜면 시스템 설정 › 일반 › 로그인 항목이 열립니다. 「백그라운드에서 허용」 목록에서 ondo를 켜 주세요. 이 한 번만 허용하면 그 뒤로는 비밀번호를 묻지 않습니다.
3. 메뉴바가 가득 차거나 메뉴바 정리 앱이 아이콘을 숨기면, Spotlight에서 ondo를 다시 열어 같은 메뉴를 창으로 띄울 수 있습니다.

## 쓰는 법

- **닫아도 깨어있기**: 메뉴의 스위치로 켜고 끕니다.
- **끄는 시점**: 무제한, 「1시간 30분 뒤」처럼 분 단위 시간, 「07:30」처럼 시각 중에서 고릅니다. 시간이 되면 깨어있기를 끄고, 뚜껑이 닫혀 있으면 바로 재웁니다.
- **온도**: 메뉴바 온도계 색이 CPU 온도를 보여 줍니다. 40°C까지는 파랑이고, 뜨거워질수록 초록·노랑·주황을 거쳐 과열 기준(기본 85°C)에서 빨강이 됩니다. 수은 높이도 함께 올라갑니다.
- **화면만 끄기**: 작업은 계속하고 화면만 끕니다.
- **잠든 뒤 다시 켜기**: 정한 시각에 맥을 깨우고 깨어있기를 다시 켭니다.

## 과열 보호

깨어 있는 동안 2초마다 온도를 읽습니다.

1. **경고**: CPU가 기준(기본 85°C)이나 배터리가 기준(기본 45°C)을 60초 넘게 넘으면 알림을 보내고, CPU를 많이 쓰는 프로그램 3개를 메뉴에 보여 줍니다.
2. **해제**: 60초를 더 넘으면 깨어있기를 끕니다. 뚜껑이 닫혀 있으면 바로 재우고, 열려 있으면 알림만 보냅니다.
3. 기준보다 3°C 아래로 내려가면 경고가 풀립니다. 기준과 그 3°C 사이에서는 시간이 멈춰서, 기준 언저리에서 경고가 반복되지 않습니다.

설정에서 「식으면 맥을 깨워 다시 켜기」를 켜면, 과열로 멈춘 뒤 정한 시간(기본 30분)이 지나 맥을 깨웁니다. 두 온도가 모두 기준보다 10°C 낮으면 다시 켜고, 아니면 다시 재웁니다. 최대 3번 확인합니다.

온도를 읽지 못하는 Mac에서는 메뉴에 그 사실을 알리고, 나머지 기능은 그대로 동작합니다.

## 전원 보호

- 깨어 있는 동안 충전기가 빠지면 끕니다(설정에서 끌 수 있음).
- 배터리로 쓰는 중 배터리가 하한(기본 20%) 아래로 내려가면 끕니다.
- 과열 중이거나 배터리가 부족하면 켜기를 거절합니다.

## 동작 원리

뚜껑을 닫아도 깨어 있게 하려면 `pmset -a disablesleep 1`이 필요하고, 이 명령은 관리자 권한이 있어야 합니다. ondo는 sudoers를 고치지 않고, `SMAppService`로 등록한 작은 도우미(LaunchDaemon)에게 맡깁니다.

- 도우미는 `disablesleep 1/0`, 깨우기 예약·취소만 합니다. 글자로 된 명령을 받지 않아서 다른 명령을 실행할 방법이 없습니다.
- 도우미는 같은 개발자 인증서로 서명한 ondo 앱의 연결만 받습니다.
- 온도는 Apple이 공개하지 않은 IOHID 센서와 SMC 키로 읽습니다. 관리자 권한은 필요 없습니다.

깨어있기가 켜진 채 남지 않도록 이렇게 되돌립니다.

| 상황 | 되돌리는 방법 |
|---|---|
| 앱 종료(⌘Q) | 앱이 도우미에 `disablesleep 0`을 요청한 뒤 끝납니다. |
| 앱이 멈추거나 강제 종료됨 | 도우미가 앱 연결이 끊긴 것을 보고 `0`으로 돌립니다. |
| 도우미가 종료 신호를 받음, 재부팅 | 도우미가 종료할 때와 부팅해서 시작할 때 `0`으로 돌립니다. |

## 외부·AI 제어

```sh
ondo status            # 상태, 남은 시간, 온도, 전원
ondo on --for 1h30m    # 1시간 30분 동안 깨어 있기
ondo on --until 07:30
ondo off
ondo temp
ondo display-off
ondo wake --in 30m     # 30분 뒤 깨워서 다시 켜기 (--at 07:00, --cancel)
ondo sensors           # 센서 전체 값 (디버그)
```

`--json`을 붙이면 JSON으로 출력합니다. 종료 코드는 0 성공, 1 오류, 2 앱에 연결 못 함, 3 보호 규칙이 거절입니다.

- **MCP**: `claude mcp add ondo -- ondo mcp`. Claude Code·Claude 데스크톱·Codex 같은 AI 앱이 같은 기능을 도구로 씁니다.
- **링크**: `ondo://on?for=1h30m`, `ondo://off`, `ondo://display-off`, `ondo://wake?in=30m`. 단축어·Raycast·Alfred에서 「URL 열기」로 씁니다.

외부에서는 켜기·끄기·상태 보기·화면 끄기·깨우기 예약만 할 수 있습니다. 과열·전원 기준은 앱 설정에서만 바뀌므로 AI 에이전트가 보호를 끌 수 없습니다.

## 주의

- Amphetamine의 Closed-Display Mode처럼 같은 `disablesleep` 설정을 쓰는 앱과 함께 쓰지 마세요. 서로 설정을 덮어씁니다.
- 덮은 맥북은 열이 잘 빠지지 않습니다. 바람이 통하는 곳에 두세요.
- 기본 과열 기준 85°C는 빌드 같은 무거운 작업에서 자주 닿을 수 있습니다. 설정에서 바꿀 수 있습니다(60~105°C).

## 삭제

1. ondo 설정 › 일반 › 「도우미 제거」를 누릅니다.
2. 앱을 종료하고 응용 프로그램 폴더에서 지웁니다. Homebrew로 설치했다면 `brew uninstall --cask ondo`.

## 직접 빌드

Xcode(Swift 6)가 필요합니다. 외부 의존성은 없습니다.

```sh
swift test                    # 단위 시험
scripts/build-app.sh          # dist/ondo.app (Developer ID 서명)
NOTARY_PROFILE=<프로필> scripts/make-dmg.sh   # 공증한 DMG (APPLE_API_KEY* 변수도 가능)
```

설계와 결정은 [SPEC.md](SPEC.md), 기능별 수동 시험은 [docs/manual-tests.md](docs/manual-tests.md)에 있습니다.
