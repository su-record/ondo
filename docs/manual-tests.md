# 수동 시험 체크리스트

기능마다 순서, 기대 결과, 마지막 확인 결과를 적는다. 「확인」은 실제 기기에서 돌려 본 것만 적고, 날짜와 기기를 남긴다.
기본 기기: MacBook Pro M5 Pro, macOS 27.0.1.

잠자기 설정 확인 명령: `pmset -g | grep SleepDisabled` (줄이 없으면 0)

## 1. 온도 센서

| 순서 | 기대 | 결과 |
|---|---|---|
| `ondo sensors` | HID `PMU tdie*`가 CPU, SMC `TB0T~TB2T`가 배터리로 선택됨. `PMU tdev*`(-9201)는 ignored | 확인 2026-11-26 (CPU 14개 센서, 배터리 3개) |
| 메뉴 › 디버그… › 센서 | 같은 목록, 쓰인 센서에 체크, 「복사」로 기기 정보와 값 복사 | 미확인 |
| 다른 칩(M1~M4, Intel)에서 `ondo sensors` | CPU 값이 나옴. 안 나오면 「복사」 내용을 이슈로 받기 | 미확인 (기기 없음) |

## 2. 도우미 승인과 켜기·끄기

| 순서 | 기대 | 결과 |
|---|---|---|
| 처음 켜기 | 시스템 설정 › 로그인 항목이 열리고, 메뉴 상태 줄에 허용 안내 | 확인 2026-11-26 (`register()`가 승인 대기를 오류로 돌려주는 것도 처리) |
| 허용 뒤 `ondo on --for 5m` | `SleepDisabled 1`, 비밀번호 창 없음 | 확인 2026-11-26 |
| `ondo off` | `SleepDisabled 0` | 확인 2026-11-26 |
| 메뉴 스위치로 켜고 끄기 | 위와 같음, 상태 줄 갱신 | 미확인 |
| 앱을 새 버전으로 바꾼 뒤 | 앱 종료 후 10초면 옛 도우미가 끝나고, 다음 요청에 새 도우미가 뜸 | 미확인 |

## 5. 과열 보호

시험 방법: 앱 종료 → `defaults write dev.torylabs.ondo settings -data "$(printf '{"cpuLimit":60,"sustainSeconds":10}' | xxd -p | tr -d '\n')"` → 앱 실행 → `ondo on` → `yes > /dev/null` 여러 개로 부하. 끝나면 `defaults delete dev.torylabs.ondo settings`.

| 순서 | 기대 | 결과 |
|---|---|---|
| 기준을 10초 넘김 | 경고 알림, 메뉴에 상위 프로세스 3개와 남은 초 | 확인 2026-11-26 (60°C 넘고 10초 뒤 경고, `yes` 3개 표시) |
| 10초 더 넘김 | 깨어있기 꺼짐(cpuHot), `SleepDisabled 0`, 뚜껑 열림이면 알림만 | 확인 2026-11-26 |
| 기준보다 3°C 아래로 식음 | 경고 해제 | 미확인 |
| 과열 중 켜기 | 거절, CLI 종료 코드 3 | 미확인 |
| 디버그 › 온도 시뮬레이션 | 메뉴에 「시뮬레이션」, 10분 뒤 자동 해제 | 미확인 |
| 뚜껑 닫힌 채 과열 해제 | 바로 잠듦 | 미확인 (뚜껑 필요) |

## 6. 과열 뒤 다시 켜기

| 순서 | 기대 | 결과 |
|---|---|---|
| 재개 켜고 과열 해제 (대기 1분) | ondo 깨우기 예약 1개, 1분 뒤 확인 | 확인 2026-11-26. 첫 시험에서는 여유 시간 60초 때문에 바로 3번 확인하고 포기했고 예약도 2개 겹쳤다. 5초로 줄이고 예약 전 취소를 넣은 뒤 재시험: 15:21:07 해제 → 예약 1개 → 15:22:07 확인 |
| 식었으면 | 다시 켜짐, 알림 | 확인 2026-11-26 (CPU 45.6°C, 기준 60°C −10 이하라 다시 켜짐) |
| 3번 모두 덜 식으면 | 포기 알림, 뚜껑 닫혀 있으면 잠듦 | 미확인 |
